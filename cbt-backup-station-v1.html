เวอร์ชัน Backup Station V1 — ฟรี / อ่านอย่างเดียว

อ่านข้อมูลอย่างเดียว ไม่มีคำสั่งล้าง/เขียนฐานข้อมูล

เครื่องมือนี้โหลดเซฟทุกบัญชีจาก Firestore ไปยังหน่วยความจำในเบราว์เซอร์ของเจ้าของ และส่งออกไฟล์ JSON/CSV ลงอุปกรณ์ของเจ้าของเท่านั้น ไม่ส่งข้อมูลผู้เล่นขึ้น GitHub

คำเตือน: นี่คือสำเนาเอกสารใน collection saves ไม่ใช่ Backup ทั้ง Firestore และไม่รับประกัน snapshot ณ เวลาเดียวกัน ต้องปิดปรับปรุงก่อนสแกน และสำรอง Firestore ด้วยระบบจัดการของ Google Cloud อีกชุด

ขั้นตอน

1) เปิดโหมดปิดปรับปรุงจาก Admin ก่อน · 2) ลงชื่อเข้าใช้ด้วย Google เจ้าของ · 3) กดตรวจทั้งหมด · 4) ดาวน์โหลด JSON และ CSV แล้วตรวจไฟล์ว่ามีข้อมูลจริง · 5) สำรอง Firestore อย่างเป็นทางการก่อนล้าง CBT

รายการเต็มอยู่ในไฟล์ CSV ซึ่งรวมทุกบัญชี แม้ไม่มี Limited เพื่อใช้ตรวจเทียบ
ชื่อUIDการ์ด LTเครื่องราง LTโล่โล่ในจดหมายข้อควรตรวจ

ตรวจสำเนา JSON + CSV บนมือถือ (ทำงานในเครื่องเท่านั้น)

เลือกไฟล์ที่ดาวน์โหลดจาก Audit V4 ทั้งคู่ ไม่มีการส่งไฟล์ไปเซิร์ฟเวอร์หรือ GitHub และไม่แก้ Firestore

ยังไม่ได้ตรวจไฟล์

สำรอง Collections เพิ่มโดยใช้ Spark ฟรี

กดหลังจากเปิดโหมดปิดปรับปรุงและเข้าระบบด้วย Google เจ้าของ เหมาะสำหรับหลักฐานเติมเงิน ค่าตั้งเกม และการชดเชยที่ไม่ได้อยู่ในเซฟ JSON

อ่านอย่างเดียวผ่านสิทธิ์ที่ Firestore Rules อนุญาต ค่าที่ส่งออกอาจไม่เก็บชนิด Timestamp เหมือนต้นฉบับ และไม่ใช่ไฟล์สำหรับ Import กลับโดยตรง
