/* ---------- b167 Endless Tower (weekly), mailbox, season shields ----------

   A fight is an ordinary stage fight (full life every floor); after a win the team RUNS on to the next floor instead of going back to a result screen.
   Five zones of 20 floors repeat; floor f is as strong as stage f x TW_K up to stage 500 (floor 200), then enemies grow by TW_GROW per floor.
   Ranking: tower/{week}/s/{player} = {f, at (server time, set only when f rises), name, ...}. The rules accept a write only into the CURRENT week, so a finished week is frozen by the server
   and nobody has to close it by hand. The first time a player opens the game in a new week the game reads the frozen table, works out the rank and puts the reward in the mailbox (S.mail).
   Shields (S.sh, codes 'T<rank>.<season>' tower top 3 and 'P<tier>.<season>' best PvP rank of a season) are Limited: account-bound, never traded, kept through the end-of-CBT wipe. */
