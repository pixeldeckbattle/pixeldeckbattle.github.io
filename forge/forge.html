โจมตี — เปลี่ยนตามอาวุธ: ดาบ/คาตานะ/มีด ฟันโค้ง · ดาบใหญ่/ขวาน/ค้อน/เคียว ทุบกระแทกพื้น · หอก แทงพุ่ง · ธนู ง้างแล้วยิงลูกธนู · คทา/ไม้กายสิทธิ์ ร่ายเวท

ร่ายเวท · โดนตี (กระพริบขาว) · ตาย (ล้มลง) · ชนะ (กระโดดชูอาวุธ)
เลือกเฟรม 4–16 ต่อท่า และเปลี่ยนเอฟเฟกต์ของทุกท่าได้

นำเข้าไฟล์ของคุณ

เอารูปที่ GPT ทำมา หรือโมเดลของคุณเอง มาใส่ท่า ใส่เอฟเฟกต์ แล้วส่งออกเป็นไฟล์ตัวละครในเกม

ไฟล์ ZIPได้ 3 แบบ: รูปเฟรมเรียงชื่อ · โฟลเดอร์ตามท่า (idle, walk, attack…) · แพ็กชิ้นส่วน (body, head, hair, weapon…)
รูปหลายเฟรมเลือก PNG หลายรูปพร้อมกัน เรียงตามชื่อไฟล์
Sprite sheetรูปเดียวที่มีหลายเฟรมเรียงเป็นตาราง
รูปตัวละครรูปเดียวแอปทำท่าให้เอง: ยืนหายใจ เดิน โจมตี ร่ายเวท โดนตี ตาย ชนะ

เลือกชิ้นส่วนจากแพ็ก

โครงสร้าง ZIP ที่รองรับ 
1) รูปเฟรมเรียงชื่อ
   hero.zip
   ├─ 01.png  02.png  03.png …

2) โฟลเดอร์ตามท่า (ไฟล์ที่แอปนี้ส่งออก นำกลับเข้ามาได้)
   hero.zip
   ├─ idle/   01.png 02.png …
   ├─ walk/   …
   ├─ attack/ …   (ชื่อท่า: idle walk run attack skill cast hit death victory)

3) แพ็กชิ้นส่วน — ทุกรูปขนาดเท่ากัน พื้นโปร่งใส วางตำแหน่งตรงกัน
   parts.zip
   ├─ 1_back/   cape_red.png …
   ├─ 2_body/   knight.png  mage.png …
   ├─ 3_head/   …
   ├─ 4_hair/   …
   ├─ 5_hat/    …
   ├─ 6_weapon/ sword.png  bow.png …   (โฟลเดอร์ชื่อ weapon จะหมุนตอนโจมตี)
   └─ pack.json   {"pivot":[จุดมือ x, y]}   (ไม่ใส่ก็ได้)
   จำนวนแบบ = คูณจำนวนรูปทุกโฟลเดอร์ เช่น 10×10×10×10×10 = 100,000 แบบ
ท่านี้ · แถบ PNGทุกเฟรมของท่าที่เลือก เรียงแนวนอนรูปเดียว
ท่านี้ · GIF ขยับพื้นโปร่งใส เอาไปโพสต์หรือดูตัวอย่าง
ท่านี้ · เฟรมแยก ZIPPNG ทีละเฟรม 01.png 02.png …
แพ็กตัวละครเข้าเกมทุกท่า: โฟลเดอร์เฟรม + sheet.png + meta.json + portrait.png
ส่งออกหลายโมเดลพร้อมกัน จากคลัง ครั้งละไม่เกิน 100 รหัส ได้ sheet.png + meta.json ของแต่ละโมเดล
